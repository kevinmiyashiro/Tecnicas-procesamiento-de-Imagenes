# ImageEnhancer — TP Procesamiento de Imágenes

Pequeña app Gradio para mejorar imágenes usando filtros clásicos.  
Subila como Space en HuggingFace.

## Ejecutar local:
```
pip install -r requirements.txt
python app.py
```

## Subir a HuggingFace:
1. Crear Space tipo Gradio.
2. Subir estos archivos.
3. Deploy automático.
